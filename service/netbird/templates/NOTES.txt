# netbird

Thank you for installing the netbird Helm chart!

This chart deploys the netbird-operator and the resources needed to enroll
this cluster (and optionally its pods) into a NetBird network.

## Verification Steps

1. **Check the operator**:
   ```bash
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
   ```

{{- if .Values.operator.gatewayAPI.enabled }}

2. **Check the gateways**:
   ```bash
   kubectl get gatewayclass
   kubectl get gateway -n {{ .Release.Namespace }}
   ```
{{- end }}

{{- if .Values.peer.enabled }}

3. **Check the routing peer**:
   ```bash
   kubectl get deployment {{ include "netbird.name" . }}-peer -n {{ .Release.Namespace }}
   kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "netbird.name" . }}-peer
   ```
{{- end }}

{{- if .Values.proxy.enabled }}

4. **Check the reverse proxy**:
   ```bash
   kubectl get deployment {{ include "netbird.name" . }}-reverse-proxy -n {{ .Release.Namespace }}
   kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "netbird.name" . }}-reverse-proxy
   ```
{{- end }}

{{- if .Values.client.enabled }}

5. **Check setup key and sidecar profile creation jobs**:
   ```bash
   kubectl get jobs -n {{ .Release.Namespace }} -l helm.sh/hook=post-install,post-upgrade
   kubectl get setupkeys,sidecarprofiles -n {{ .Release.Namespace }}
   ```
{{- end }}

## Troubleshooting

**If the operator is not ready:**
```bash
kubectl describe pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
kubectl get crd | grep netbird.io
```

{{- if .Values.client.enabled }}

**If setup key or sidecar profile jobs fail:**
```bash
kubectl logs -n {{ .Release.Namespace }} jobs/create-key-{{ include "netbird.name" . }} --follow
kubectl logs -n {{ .Release.Namespace }} jobs/create-profile-{{ include "netbird.name" . }} --follow
```
{{- end }}

## Cleanup

To remove all resources:
```bash
helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
```
